## 2. ¿Qué tan confiable es recuperar requerimientos a partir del código? ¿Qué se pierde?

La recuperación a partir del código permite obtener evidencia concreta sobre
las funciones que fueron implementadas, las vistas disponibles, los menús,
los controladores y las operaciones realizadas.

Sin embargo, pueden perderse las necesidades originales del usuario, reglas
de negocio que no quedaron documentadas, requisitos que fueron descartados,
restricciones del proceso y decisiones tomadas durante el desarrollo.

Por eso, el código es una fuente importante de evidencia, pero no representa
necesariamente la totalidad de los requerimientos originales.

Se debería comparar la evidencia utilizada por cada equipo y revisar los
archivos concretos que respaldan cada conclusión. También se debe validar el
comportamiento del sistema cuando exista una instalación disponible.

la validación con el proceso institucional, en lugar de elegir una lista
