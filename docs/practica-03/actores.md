# Práctica 03 - Actores del sistema

## Objetivo

Identificar los actores y roles del sistema a partir del código existente,
principalmente de Vistas/plantilla.php y de los archivos de menú.

## Evidencia revisada

- Vistas/plantilla.php
- Vistas/menu.php
- Vistas/menuAlumno.php
- Vistas/menuAcademico.php
- Vistas/menuIndustrial.php
- Vistas/menuJefe.php
- Vistas/modulos/
- Controladores/

## Actores identificados

| Actor / Rol | Evidencia | Descripción |
|---|---|---|
| Admin | Vistas/plantilla.php / menú general | Usuario administrativo con acceso a funciones generales de gestión del sistema. |
| Alumno | Vistas/plantilla.php / menuAlumno.php | Usuario que consulta y realiza acciones relacionadas con su proceso de residencia. |
| a_Academico | Vistas/plantilla.php / menuAcademico.php | Asesor académico que participa en la revisión y seguimiento del proceso. |
| a_Industrial | Vistas/plantilla.php / menuIndustrial.php | Asesor externo/industrial relacionado con el seguimiento del alumno. |
| Jefe | Vistas/plantilla.php / menuJefe.php | Responsable de funciones de revisión y gestión asociadas al proceso. |
